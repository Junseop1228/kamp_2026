# notes/ — 개인 작업 노트

역할 기준으로 분리한다. 실명·소속·개인 식별정보를 이 리포지토리 어디에도 남기지 않는다.

| 경로 | 역할 | 다루는 것 |
|---|---|---|
| `lead/` | 총괄 | 평가 설계, 문헌, 제출물 관리, 일정 |
| `pipeline/` | 엔지니어링 | 파이프라인 코드, 환경, 실험 실행 |
| `domain/` | 도메인 | 공정 해석, 물리 기반 파생변수 설계, 결과 검증 |

## 성격

여기는 **작업 중 사고 과정**이 남는 곳이다. 정리된 결론은 여기 두지 않는다.

- 결정 → `docs/03_decision_log.md`
- 실험 → `experiments/`
- 오류 → `known_issues/`
- 규칙 → `docs/01_team_workflow/`

노트는 위 네 곳으로 승격되기 전의 초안이다. 승격되면 노트에 링크만 남기고 본문은 옮긴다.

## 규칙

- 파일명은 소문자 snake_case 영문. 날짜를 쓰면 `YYYY-MM-DD` 접두
- 남의 디렉토리를 편집하지 않는다
- 보고 수치를 여기에 적어두고 인용하지 않는다. 수치의 출처는 `results/metrics.json` 하나다 (WD-01)
