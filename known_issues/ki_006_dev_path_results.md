# KI-006. 개발 경로로 만든 산출물이 정식 실행 결과와 끝자리에서 달랐다

- **태그** #process
- **등록일** 2026-10-07
- **상태** 닫힘 (정식 실행 결과로 교체)
- **출처** P8 재현 점검(새 클론 + 새 환경 + `run.py` 1회 실행)
- **관련 문서** `../docs/03_decision_log.md` D-012

## 무엇이 일어났나

새 클론에서 만든 결과 72개 중 6개(두 제품군의 `alarm_labeled.csv`, `alarm_test.csv`, `predictions_meta.json`)의 해시가 커밋된 결과와 달랐다. 차이는 소수점 16번째 자리뿐이고 알람 기준·울린 배치·개수 같은 판정은 모두 같았다.

## 원인

P7 산출물을 만들 때 40분짜리 전체 실행을 피하려고, 저장된 교차검증 결과 CSV를 다시 읽어 알람을 계산하는 개발용 경로를 썼다. CSV 저장·재읽기에서 부동소수 끝자리가 바뀌어, 메모리에서 바로 계산하는 정식 실행과 결과가 달라졌다.

## 조치

커밋된 6개 파일을 새 클론의 정식 실행 결과로 교체했다. 교체 후 `run_record.json`을 뺀 결과 72개가 새 클론 결과와 모두 같다.

## 교훈

커밋하는 산출물은 `run.py` 1회 실행으로만 만든다. 개발용 지름길로 만든 결과는 확인용으로만 쓰고 커밋하지 않는다.
