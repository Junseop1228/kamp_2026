## D-007. Evaluate 판정·교차검증 규칙 사전 선언

- **일자** 2026-10-04
- **상태** 확정
- **결정**
  1. 판정은 순위 기반이다. 평가 배치마다 점수 상위 k%를 표시하고 확률 임계값은 쓰지 않는다. k는 학습 fold의 불량률이다
  2. 표시 개수 = floor(k × 배치 크기 + 0.5), 최소 1. 경계 점수와 같은 제품은 전부 표시하고 명목·실제 표시 수를 둘 다 기록한다
  3. 교차검증은 그룹 단위 `StratifiedGroupKFold`, fold 수 = min(5, 불량 그룹 수), seed 0~9로 10회 반복한다. 불량 그룹이 2개 미만이면 학습 불가로 중단한다
  4. 판정은 fold마다 하고, 채점은 반복마다 전 fold를 합쳐 F1(주지표)과 PR-AUC를 한 번씩 낸다
  5. 무작위 하한 F1(≈ 불량률)과 중복 상한 F1을 항상 함께 표시하고, 모델 F1 ÷ 상한을 보고한다
- **배경** 프레임워크 설계에서 확정한 규칙이다. 모델 결과가 나오기 전에 설정(`configs/injection.json`의 `cv`·`threshold`)·코드·테스트와 함께 커밋해 사전 선언의 증거로 남긴다.
- **대안과 기각 사유**
  - 학습 fold 안에서 임계값 조정 — 학습 fold 안 불량이 3개 안팎이라 불안정하다. 기각

## D-009. 모델 라인업·선택 규칙·보고 전용 분석 사전 등록

- **일자** 2026-10-06 (모델 결과 확인 전, 모델 코드 작성 전)
- **상태** 확정
- **결정**
  1. 선택 후보 6개, 복잡도 순서 `deviation_score` < `logistic` < `random_forest` < `hist_gb` < `guidebook_dae` < `soft_vote_ensemble`. `random_score`는 하한 기준이며 선택 대상이 아니다
  2. 설정값은 `configs/injection.json`의 `models.params`가 단일 원천이다. 지도학습 모델은 불균형 가중치(`balanced`)로 학습한다. CV 결과를 본 뒤 손으로 바꾸지 않는다
  3. 가이드북식 기준모델(`guidebook_dae`)은 가이드북 1부 잡음제거 오토인코더를 모델 계약에 맞춰 다시 구현한다 — 양품만 학습, train 상수 변수 제외, MinMax는 fold 안에서 학습, 입력 30% 가림(10배 복제)으로 Dropout 대체, 은닉 15-5-15 ReLU, Adam, 배치 30, 최대 30에포크, 검증 20% 조기종료(patience 5), 점수 = 복원오차 e / (e + 학습 양품 오차 중앙값). 가이드북 2부(labeled·unlabeled 합친 준지도 학습)는 금지 규칙(unlabeled 합쳐 쓰기)에 해당해 재현하지 않는다. 2부 평가셋 불량 수(RG3 83·CN7 56)가 파일 전체 불량 수(25·17)보다 많다는 사실은 보고서에 근거로 싣는다
  4. 확률 출력: 불균형 가중치로 학습한 모델은 사전확률 보정 p' = p·r / (p·r + 1 − p), r = 학습 불량 수 / 양품 수를 적용한다. 라벨로 학습하는 보정이 아니며 순위가 바뀌지 않으므로 F1·PR-AUC·표시 결과는 그대로다. 점수형 모델(`deviation_score`, `guidebook_dae`)은 위험 점수로 내고, 확률 해석은 검사 구간별 실측 불량률로 제시한다. 보정 품질은 교차검증 예측의 평균 예측확률과 Brier 점수로 보고한다
  5. 선택 규칙: 평균 F1 최고 모델과 각 모델의 같은 seed(같은 fold) 쌍별 F1 차이를 구해, 차이의 평균 ≤ 차이의 표준편차(ddof=1)이면 "차이 없음"으로 본다. 최고 모델과 "차이 없음" 모델 중 복잡도 순서상 가장 단순한 모델을 고른다. 제품군별로 따로 고른다
  6. 보고 전용(선택에 쓰지 않음) — 누수 대조(선택 모델을 그룹을 무시한 StratifiedKFold로 5×10), 블록 분할(파일 순서 연속 5블록, 그룹은 첫 행 위치로 배정, 1회), 입력 20개 민감도(선택 모델, 5×10), 판정 확신도(seed 10개 모델의 표시 비율, test와 교차검증 예측 모두)
  7. 2차 데이터셋 검증(P9)은 하지 않는다
- **배경** 과제공개 원문 2번(베이스라인 포함 2개 이상 비교, 선정근거)과 5번 예시(앙상블·불확실성 추정·확률보정), 결과보고서 양식 제5장 작성요령(방법의 기여를 제2·3장 결과에 연결). 결과를 보기 전에 커밋해 사전 등록의 증거로 남긴다.
- **대안과 기각 사유**
  - 배치 안 순위 평균 앙상블 — 점수가 배치 구성에 따라 달라져 모델 계약 위반(KI-004). 확률 평균(soft voting)으로 대체
  - 보정 모델 학습(Platt·isotonic) — 불량 17·25개로 불안정하다. 기각(기존 폐기 사유 유지). 사전확률 보정은 라벨로 학습하지 않으므로 이 사유에 해당하지 않아 재도입한다
  - 선택 규칙의 표준편차를 모델별 F1 표준편차로 정의 — 같은 fold를 공유하는 짝 구조를 버린다. 쌍별 차이의 표준편차를 채택
  - GPU 가속 — 학습 데이터가 제품군당 약 1,200행 × 24열이라 전송 비용이 계산 이득보다 크다. CPU 병렬(`n_jobs`)만 쓴다
  - P9 — 서면 평가항목에 확장성이 없고, 원문이 팀별 1종 선택이며, 양식 제5장 기준(제2·3장 결과와의 연결)에 기여하지 않는다
- **감수한 리스크**
  1. 가이드북 원문 코드가 이미지라 은닉층 구성 일부와 patience는 추정값이다. "가이드북식"으로 부르고 원문과 다른 점을 표로 공개한다
  2. 트리 모델에 대한 사전확률 보정은 근사다
  3. 후보 6개 중 고르므로 최고값 선택 편향이 있다. 선택 규칙이 단순 모델을 우선하고, 모든 후보의 결과를 공개한다
- **재검토 시점** 없음

## D-011. Analyze 설정과 사후 탐색 범위

- **일자** 2026-10-06 (Analyze 결과 확인 전 설정, 사후 탐색은 명시)
- **상태** 확정
- **결정**
  1. 분석 대상은 선택 모델이다. FN 유형 분류만 비교한 후보 6개 전부를 쓴다
  2. permutation 중요도: 평가 fold에서 변수 하나를 섞어 PR-AUC 하락을 잰다. 학습 1회당 5번 섞고, 5-fold × 10회 = 50회 학습 중 상위 5위에 든 비율을 신뢰도로 쓴다
  3. 상위 2개 변수: 신뢰도 순 첫 변수, 그리고 그와 거의 같은 변수(|r| ≥ 0.95)가 아닌 다음 변수. 같은 정보를 두 번 세지 않는다
  4. 상호작용은 두 변수를 중앙값으로 나눈 2×2 표, 2D 부분의존도는 5~95% 분위 10×10 격자. 서술용이다
  5. FN 유형(반복 10회 순위 비율의 중앙값 기준): 잡힘(1k 안) / 경계(1k~aux_k) / 모델 차이(선택 모델은 aux_k 밖, 다른 후보 하나라도 aux_k 안) / 신호 없음(모든 후보가 aux_k 밖). aux_k = 불량률 × 불량이 든 그룹의 평균 크기
  6. FN 집중 조건: 상위 2개 변수의 4분위 구간별로 잡힌 불량과 놓친 불량을 센다(과제공개 원문 3번 요구, 기존 계획에 없던 항목)
  7. FP 분석은 검사량 10%에서 한다. 구조적 FP(불량이 든 그룹의 양품)와 조건 FP(그 밖의 양품)를 나누고, 조건 FP 비율을 상위 2개 변수 4분위별로 전체 비율과 비교한다
  8. 도메인 대조: 상위 5개 변수의 예상 관계(변수 사전 AI 초안) vs 불량의 관측 방향(양품 기준 z). 불일치는 결론이 아니라 검토 과제로 적는다
  9. **사후 탐색(명시):** 누수 대조를 `random_forest`·`hist_gb`로 넓힌다. 선택 모델(`logistic`)에서 쌍 누수 부풀림이 나타나지 않아(D-010), 고용량 모델에서는 나타나는지 확인한다. 선택·판정에 쓰지 않는다
  10. 어떤 후보도 하한을 넘지 못한 제품군(RG3)도 같은 분석을 돌리되, 영향요인·상호작용은 "해석하지 않음"으로 표기한다
- **배경** 과제공개 원문 3번(주요 영향변수, 상호작용, FN·FP가 집중되는 공정조건)과 결과보고서 양식 제3장(잘 작동하는 조건과 실패하는 조건 구분).
- **대안과 기각 사유**
  - SHAP — 환경에 없는 패키지가 필요하고, 선택 모델이 선형이라 계수와 permutation으로 충분하다. 기각
  - FN·FP 집중 조건에 통계 검정 — 불량 17·25개로 칸이 너무 작다. 서술만 한다
- **감수한 리스크**
  1. 평가 fold당 불량이 3~5개라 PR-AUC 하락이 거칠다. 신뢰도(상위 5위 비율)를 함께 보고한다
  2. 순위 비율의 중앙값은 반복 판정의 근사다. 실제 표시 수와 조금 다를 수 있다
  3. 2D 부분의존도는 두 변수만 움직이고 나머지는 그대로 두므로, 상관이 강한 변수 조합에서는 실제로 없는 조건을 포함할 수 있다
