## 1. 회차별 개요

| 회차 | 연도 | 대상 데이터셋 | 과제해결 기간 | 발표평가 진출 |
|---|---|---|---|---|
| 제2회 | 2022 | 용해탱크 (단일) | 10/26~11/09, 14일 | 8팀 |
| 제3회 | 2023 | 열처리 품질보증 (단일) | 10/23~11/03, 12일 | 8팀 |
| 제4회 | 2024 | 주조 공정최적화 (단일) | 10/24~11/06, 14일 | 10팀 |
| 제5회 | 2025 | 열처리·소성가공·사출성형 3종 중 팀별 1종 선택 | 10/21~11/03, 14일 | 8팀 |
| 제6회 | 2026 | 50종 중 1종 또는 여러 종 (미공개) | 9/21~10/08, 18일 | 미확보 |

**핵심 발견 1 — 데이터셋은 무작위 배정이 아니다.**
제2~4회는 전 참가팀에 동일한 단일 데이터셋이 주어졌고, 제5회는 3종 중 팀이 직접 선택하는 방식이었다.
제6회 공고의 "50종 중 1종 또는 여러 종을 활용하여 문제 출제 예정"은 제5회식 선택형(추정)에 가깝다.
50종 전체가 주어지는 것이 아니라 **소수 후보군이 제시되고 그중 고르는 구조**로 보는 것이 타당하다.

**핵심 발견 2 — 과제 구조가 4~5년째 동일하다.**
매 회차 "제조현장 문제 / 분석 목적 / 해결과제" 3열 표로 4~5개 예시 과제가 제시된다.
반복되는 축: 장비이상 조기탐지(예지보전), 품질공정 제어(공정 최적화), 품질이상 탐지·진단, 자원 최적화.
제5회에 공급망 최적화가 추가됐다.
**참가팀은 예시 중 하나를 고르거나 자체 주제를 잡아 자유롭게 접근한다.** 정답이 정해진 스코어 대회가 아니다.

## 2. 평가 배점 (제2~5회 4년 연속 동일)

### 서면평가 100점

| 구분 | 지표 | 배점 |
|---|---|---|
| 정량 (30) | AI 성능 정확도 | 30 |
| 정성 (70) | 제조현장 문제 이해도 | 10 |
| | 제조AI데이터셋 이해도 | 10 |
| | 문제 정의 체계성 | 10 |
| | 분석모델 독창성 | 10 |
| | 분석 과정 타당성 | 10 |
| | 결과해석 우수성 | 10 |
| | 결과물 작성 충실성 | 10 |

### 발표평가

| 지표 | 배점 |
|---|---|
| 발표능력 우수성 | 10 |
| 문제해결 독창성 | 20 |
| 분석 과정 적절성 | 20 |
| 분석모델 적용 가능성 | 20 |
| 분석모델 확장성 | 30 |

제2·3회는 총점 100 표기, 제4·5회는 총점 70 표기(합계는 100). 제5회에서 확장성 항목에 "사업성 포함"이 추가됐다.

### 산출 방식 (제4·5회 명시)

- 평가위원 산·학·연 5인 내외
- 위원별 점수 중 최고·최저 제외 후 산술평균, 소수점 첫째자리 이하 절사
- 최고 또는 최저가 복수면 하나만 제외
- 동점 시 **정성지표 총합 > 정량지표 점수** 순
- 평가위원과 소속기관이 같은 팀은 해당 위원 점수에서 제외

**핵심 발견 3 — 성능은 30점이고, 동점이면 정성이 이긴다.**
정량 30 / 정성 70 구조가 4년째 고정이다. 성능만으로는 서면 통과가 불가능하고, 동점 처리 기준까지 정성 우선이다.
다만 30점을 버려도 안 된다. 성능은 통과 조건이지 승부처가 아니라는 뜻이다.

**핵심 발견 4 — 발표평가에서 확장성이 단일 최대 배점(30)이다.**
"동종 및 타 업종으로의 확장 가능 정도". 특정 공정에만 통하는 모델은 여기서 깎인다.
데이터셋 불가지 재사용 파이프라인 전략이 이 항목과 정확히 맞물린다.

## 3. 제출물 (제3~5회 동일)

- 보고서 — 주최 측 첨부양식, PDF 제출
- 발표자료 — 자유양식, **PDF와 PPT 둘 다** 제출
- 소스코드 — .ipynb (노코드 도구 사용 시 분석 단계별 화면 캡처)
- 제5회 추가 — 구글폼 설문 응답 후 완료화면 캡처를 보고서에 첨부

제출: KAMP 포털 → 알림마당 → KAMP 경진대회 → 대회 선택 → 과제 제출
개발환경은 자체 환경 / KAMP-NOTE / KAMP AI-PaaS 중 선택이며, **신청 시 선택한 환경은 이후 자유롭게 변경 가능**하다.

**핵심 발견 5 — 발표자료를 서면평가 단계에서 함께 낸다.**
발표평가 진출 후에 만드는 것이 아니다. 과제해결 마감일에 보고서·발표자료·코드를 한꺼번에 제출한다.
제6회 일정(제출 10/8 → 서면평가 10/12~10/23)에 대입하면 **10/8까지 발표자료까지 완성**해야 한다.

**핵심 발견 6 — 마감이 종일이 아니다.**
제3·4회는 마감일 13시, 제5회는 14시 마감이었다. 제6회 "10.8.(목)"의 시각은 미확보이며, **오후 마감 가정으로 계획한다.**

## 4. 발표평가 진출작 경향 (34팀)

### 제2회 (용해탱크) — 8팀
준지도학습 기반 불량 탐지 / 시계열 품질 예측 / 설명가능 불량 예측 최적화 / 알고리즘 비교 기반 운영 방안 / 품질오류 예지분석 등

### 제3회 (열처리) — 8팀
저자원 환경 실시간 모니터링 / 설명가능 이상치 탐지 / 불량검출·예지보전·공정제어 통합 / 딥러닝 불량 예측 및 요인 분석 / 실시간 조건 이상탐지 / 3단 cascade 불량예측 / 각도 기반 레이블링과 데이터 증강

### 제4회 (주조) — 10팀
딥러닝 고장 예측 + 역설계 최적 후보군 탐색 / AI 품질지표 생성 기반 범용 불량 예측 / MLOps·LLM 실시간 모니터링 플랫폼 / 다이캐스팅 품질 예측 및 공정 최적화 / 불균형 데이터 문제 해결 / 샘플링 검사 기반 설명가능 공정 레시피 추천 / XGBoost 결함 감지

### 제5회 (3종 선택) — 8팀
공정 최적화 AI 에이전트 / Hierarchical MIL 불량률 예측 / CatBoost 기반 운전창 제시 / **CNN+PINN 결합 저데이터 고신뢰도 예측** / **물리식 기반 시계열 회귀** / 시퀀스 임베딩 2단계 수요 예측 / AE+LGBM 하이브리드 이상탐지 + LLM RAG 원인 분석 / 불완전 데이터에 강건한 적응형 다변량 시계열 이상탐지

### 읽히는 것

1. **단일 모델 제출은 없다.** 전부 "무엇을 위한 무슨 시스템"이라는 형태다. 예측 + 원인 분석, 탐지 + 대응, 예측 + 최적화처럼 두 단계 이상을 엮는다.
2. **설명가능성이 반복 등장한다.** 2·3·4회 모두 XAI 계열 제목이 있다. 정성 70점 구조의 직접적 결과다.
3. **제목이 곧 차별화 선언이다.** "저자원 환경에서", "불완전 데이터에 강건한", "샘플링 검사 기반"처럼 제약 조건을 먼저 규정하고 그에 맞춘 해법을 제시한다.
4. **제5회에서 물리 기반 접근이 2팀 진출했다.** PINN, 물리식 기반 회귀. 도메인 지식을 모델 구조에 직접 넣는 방향이 통했다는 신호다.
5. **최신 기술 접목이 늘고 있다.** 4회 MLOps·LLM, 5회 AI 에이전트·LLM RAG. 다만 이것들은 독창성 항목용이지 성능용이 아니다.

## 6. 미확보 항목 갱신

과거 자료로 해결된 것 — 서면평가 제출물 형식, 심사 배점표, 발표평가 형식(전 회차 기준). 모두 **제6회 확정 아님**.

여전히 미확보:
- 제6회 서면평가 배점표 — 트랙 분리로 배점이 달라졌을 가능성
- 제6회 보고서 양식 — 과거엔 과제공개 시점에 함께 배포
- 10/8 제출 마감 시각
- 발표평가 대면/비대면 여부 (제2~4회 KAIST 문지캠퍼스 메타버스, 제5회 비대면 사전미팅)
- 제6회 발표평가 진출 팀 수 (트랙별 몇 팀인지)

## 7. 전략에 미치는 영향

1. **"데이터셋 불가지" 전제는 유지하되 강도를 낮춘다.** 과거 4회 모두 소수 데이터셋이 사전 지정됐다. 제6회도 후보군이 제시될 가능성이 높으므로(추정), 완전 범용 파이프라인보다 **빠르게 적응하는 파이프라인**이 맞다.
2. **성능 30점은 통과 조건, 승부는 정성 70점.** 임시 지침의 "스코어 대회 아님"은 과거 배점표 기준으로 옳았다. 다만 제6회 공고의 트랙별 평가 중점에 "분석 성능"이 명시돼 있어 비중 상향 가능성이 있다.
3. **발표평가 최대 배점은 확장성(30).** 재사용 파이프라인 자체를 확장성 근거로 제시할 수 있다.
4. **제출물이 3종이다.** 10/8까지 보고서 + 발표자료(PDF·PPT) + 코드를 전부 완성해야 한다. 마지막 3일은 문서 작업으로 확보한다.
5. **도메인 담당 축이 배점에 직접 닿는다.** 제조현장 문제 이해도(10) + 제조AI데이터셋 이해도(10) + 결과해석 우수성(10) = 30점이 도메인 해석 영역이다. 정량 30점과 같은 크기다.
