# results/ — 보고용 확정 산출물

이 디렉토리는 **git으로 추적된다.** `outputs/`와 혼동하지 말 것.

| 디렉토리 | 추적 | 성격 |
|---|---|---|
| `outputs/` | 무시 | 실험 부산물, 스크래치. 언제 지워도 됨 |
| `results/` | **추적** | 보고서·발표자료에 들어가는 확정 산출물 |

## 구성

- `metrics.json` — **모든 보고 수치의 유일한 출처.** 파이프라인만 이 파일을 갱신한다 (WD-01)
- `figures/` — 보고서·발표자료에 삽입되는 그림. `src/viz/` 스크립트가 생성한다 (WD-05)

## 금지

- 손으로 `metrics.json`을 편집하지 않는다
- 파이프라인 밖에서 만든 그림을 `figures/`에 복사하지 않는다
- 보고서·PPT에 여기 없는 숫자를 쓰지 않는다

규칙 전문은 `docs/01_team_workflow/work_discipline.md` 참조.
